# Bible Reader content — FA-Persian

This repository contains the Bible Reader SD-card content for **FA-Persian**.

## Directory layout

- `text/FA-Persian/` — all Bible translations and their original nested folder structure.
- `audio/FA-Persian/` — audio Bible book folders and chapter MP3s.
- `gospel/FA-Persian/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
